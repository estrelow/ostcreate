Add-in for New Outlook that allows to create an osTicket support ticket from a mail message.

osTicket <https://github.com/osticket/osticket> is a support platform based in PHP. I have no relation to that project. Please check their repository and https://osticket.com/ for further info.

An end user can create a support ticket directly in the website that hosts the osTicket portal. An additional feature lets osTicket to monitor a special mailbox in order to automatically create tickets. 
But what if a user sends a mail to the support staff directly? The way the mail flows works under an Microsoft Exchange/Outlook environment, the moment to reroute a mail message is long gone by the time it appears inside the Outlook app.

osTicket comes with an API connector that allows creating tickets from another app. This Outlook add-in does exactly that.
